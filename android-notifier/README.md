# 자비샵 입금알림 (BankNotifier)

하나은행 앱의 입금 알림을 감지해서 자비샵 서버로 전달하고, 서버가 대기 중인 포인트
충전 신청과 금액+입금자명이 정확히 일치할 때만 자동으로 승인하는 안드로이드 앱입니다.

**이 폴더는 소스 코드만 있습니다.** 이 서버(리눅스, Android SDK 없음)에서는 `.apk`로
빌드할 수 없어서, 아래 순서대로 본인 PC의 Android Studio에서 직접 빌드해야 합니다.

## 왜 자동으로 승인하지 않을 때가 있나요? (중요)

아래 경우엔 **절대 자동 승인하지 않고**, 대신 디스코드로 관리자 전원에게 알림만 보냅니다.
반드시 `/admin/payments`(또는 봇의 `/충전목록`)에서 직접 확인 후 승인해주세요.

- 금액은 같은데 입금자명이 일치하는 대기 신청이 **없는** 경우
- 금액+입금자명이 일치하는 대기 신청이 **2건 이상**인 경우 (누가 보낸 건지 애매함)
- 알림 문구에서 금액/입금자명을 제대로 못 읽어낸 경우

잘못 자동 승인해서 실제로 입금 안 한 사람에게 포인트가 충전되는 사고보다, 사람이 한 번
더 보는 게 안전하다는 원칙으로 설계했습니다.

## 빌드 방법

1. Android Studio 설치 (최신 버전 권장)
2. `android-notifier` 폴더를 **Open** (이 폴더 자체를 프로젝트로 열기)
3. Gradle Sync가 자동으로 진행됩니다 (인터넷 필요, AGP/Gradle 버전이 안 맞다고 뜨면
   Android Studio가 제안하는 "Upgrade" 버튼을 눌러 자동 업그레이드하면 됩니다)
4. 상단 메뉴 **Build → Build Bundle(s) / APK(s) → Build APK(s)**
5. 빌드된 `.apk`를 폰에 설치 (또는 USB로 연결해 **Run ▶** 버튼으로 바로 설치+실행)

## 폰에서 설정하는 방법

1. 앱 실행 → 아래 값 입력 후 **저장**
   - **서버 웹훅 URL**: `https://jabishop.krl.kr/api/webhooks/bank-topup`
   - **비밀키**: 서버 `.env`의 `BANK_WEBHOOK_SECRET` 값과 **정확히 동일**해야 합니다
     (관리자에게 문의해서 받으세요)
   - **은행 앱 패키지명**: 기본값은 `com.kebhana.hnbank`(하나은행 앱 추정 패키지명)이지만,
     정확한 값은 **설정 → 앱 → 하나은행** 화면에서 확인해서 다르면 고쳐주세요. 패키지명이
     틀리면 알림을 아예 감지하지 못합니다.
2. **알림 접근 권한 설정 열기** 버튼 클릭 → 목록에서 "자비샵 입금알림" 찾아서 권한 허용
   (안드로이드가 별도 보안 확인 화면을 띄울 수 있습니다)
3. **테스트 전송** 버튼으로 서버 연결 확인 (디스코드로 관리자에게 테스트 알림이 가면 성공)
4. 배터리 최적화 예외 설정도 해주세요 (설정 → 배터리 → 앱별 배터리 사용 → 이 앱 →
   "제한 없음"). 안 하면 안드로이드가 앱을 꺼버려서 알림을 못 받을 수 있습니다.

## 알림 문구 파싱이 안 맞으면

`BankNotificationListenerService.kt`의 `parseAmount()` / `parseDepositorName()` 함수가
정규식으로 금액/입금자명을 추출합니다. 실제 하나은행 알림 문구가 예상과 다르면 이 두
함수만 고치면 됩니다. 파싱에 실패해도 원문(`rawText`)은 그대로 서버로 전달되어 관리자
디스코드 알림에 표시되니, 급하면 파싱 실패 상태로도 수동 확인은 계속 가능합니다.

## 보안 주의사항

- 비밀키는 서버와 이 앱만 아는 값입니다. 캡처/공유하지 마세요.
- 이 앱은 자동 백업(`allowBackup=false`)을 꺼뒀습니다 - 비밀키가 클라우드 백업으로
  새는 것을 막기 위함입니다.
- 알림 접근 권한은 기기의 **모든** 알림을 읽을 수 있는 강력한 권한입니다. 이 앱은 설정된
  은행 앱 패키지명이 아닌 알림은 전부 무시하지만(코드 확인 가능), 신뢰할 수 있는 본인
  기기에만 설치하세요.
